#  TaskFlow - Productivity Dashboard

Task Flow is a responsive productivity dashboard built with **HTML, CSS, and JavaScript**. It allows users to log in, manage daily tasks, track progress, and view dynamic information such as weather updates and motivational quotes using external APIs.

This project was developed to strengthen my front-end development skills and demonstrate practical JavaScript concepts including DOM manipulation, asynchronous programming, API integration, and responsive user interface design.

##  Features

### User Authentication
- Login screen
- Username validation
- Personalised dashboard greeting

### Task Management
- Add tasks
- Delete tasks
- Mark tasks as completed
- Real-time task statistics
- Dashboard showing:
  - Total Tasks
  - Completed Tasks
  - Remaining Tasks

### Dashboard
- Personalised welcome message
- Modern responsive layout
- Interactive cards
- Task progress overview

### API Integration
- Daily motivational quotes
- Current weather information

### User Experience
- Responsive design
- Clean modern interface
- Error handling for API requests
